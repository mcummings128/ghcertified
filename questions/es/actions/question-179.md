---
question: "Estás considerando una acción de Marketplace para utilizar en tu flujo de trabajo. ¿Cuáles son algunos aspectos que puedes buscar que indiquen que la acción es confiable?"
documentation: "https://docs.github.com/en/actions/reference/security/secure-use#using-third-party-actions"
---

- [x] Una insignia de 'Verified Creator' en la página de Marketplace para la acción
- [x] El README es completo en definir el propósito de la acción y cómo funciona
- [ ] El `action.yml` es muy breve
- [ ] La cantidad de estrellas es baja en la página de Marketplace para la acción
- [ ] El código fuente de la acción no se ha actualizado en mucho tiempo, lo que indica que el desarrollo de esa acción ha terminado
> Si el repositorio que contiene la acción no se ha actualizado en mucho tiempo, las dependencias y elementos similares pueden estar desactualizados, presentando posibles riesgos de seguridad.
